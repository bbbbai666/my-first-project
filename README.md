# 番茄钟学习计时器

> 基于人脸检测 + 屏幕活动检测的自动学习时长统计工具。
> 只在你真正学习时计时，离开即停，离开超 20 分钟自动结束本次会话。

---

## 功能特性

| 功能            | 说明                                                         |
| --------------- | ------------------------------------------------------------ |
| 自动开始计时    | 检测到人脸 + 鼠标活动即自动开始，无需手动点击                |
| 人脸检测        | 调用摄像头，使用 OpenCV Haar 级联分类器识别面部              |
| 屏幕活动检测    | 周期采样鼠标位置，判断是否在操作电脑                         |
| 离开即停        | 检测失败立即停止计时                                         |
| 超时自动结束    | 离开超过 **20 分钟** 自动结束本次会话并写入日志              |
| 手动暂停 / 继续 | 支持暂停和继续，但检测功能始终运行、不可关闭                 |
| 手动结束        | 随时结束本次会话                                             |
| MD 学习记录     | 每次会话结束自动追加到桌面 `学习记录.md`，含日期、单次时长、今日累计、今日合计 |
| 每次从零计时    | 会话结束后下次检测通过即开启新会话，时长重新从 0 开始        |

---

## 检测逻辑

- **检测周期**：每 5 秒执行一次综合检测。
- **判定为"在学习"**：同时满足 ① 摄像头检测到人脸 ② 最近 30 秒内有鼠标活动。
- **摄像头不可用时**：自动降级为仅活动检测（不影响基本使用，但精度下降）。
- **检测功能不可关闭**：手动暂停只暂停计时，检测始终在后台运行。

## 编译与运行

### 方式一：Maven（推荐）

需要本机已安装 JDK 11+ 和 Maven。

```bash
cd Desktop/PomodoroStudyTimer

# 编译并打包（首次会下载 JavaCV 依赖，约 700MB，请耐心等待）
mvn package

# 运行
java -jar target/pomodoro-study-timer-1.0.0.jar
```

### 方式二：IDE

用 IntelliJ IDEA 打开 `PomodoroStudyTimer` 文件夹，Maven 会自动导入依赖，
然后直接运行 `pomodoro.StudyTimerApp` 的 `main` 方法。

## 首次运行须知

1. **摄像头权限**：Windows 首次运行会弹出摄像头授权提示，请允许。
2. **模型下载**：首次启动会自动从 GitHub 下载 Haar 级联模型（约 1MB）到
   `~/.pomodoro/haarcascade_frontalface_default.xml`，需联网。
3. **摄像头指示灯**：程序运行期间摄像头指示灯会常亮，属于正常现象（周期性抓帧检测）。
4. **学习记录位置**：`C:\Users\<用户名>\Desktop\学习记录.md`

## 界面说明

```
┌──────────────────────────────────┐
│       番茄钟学习计时器            │
│                                  │
│        状态：学习计时中           │
│        本次：25:00                │
│        今日总计：50:00            │
│     正在学习，检测正常            │
│                                  │
│      [暂停]   [结束本次]          │
└──────────────────────────────────┘
```

- **状态**：待机 / 学习计时中 / 已离开 / 手动暂停
- **本次**：当前会话累计学习时长（从 0 开始）
- **今日总计**：今日所有已记录会话 + 当前会话
- **暂停**：手动暂停计时（检测继续运行）；再次点击继续
- **结束本次**：手动结束并写入日志，下次检测通过自动开始新会话

## 常见问题

**Q: 摄像头打不开怎么办？**
A: 检查是否有其他程序占用摄像头，或 Windows 隐私设置中是否允许应用访问摄像头。
   程序会自动降级为仅活动检测，不影响基本使用。

**Q: 模型下载失败？**
A: 手动下载 `haarcascade_frontalface_default.xml`（可从 OpenCV 官方仓库），
   放到 `C:\Users\<用户名>\.pomodoro\` 目录下。

**Q: 学习记录在哪？**
A: 桌面的 `学习记录.md` 文件，每次会话结束自动追加。

**Q: 计时不准？**
A: 检测周期为 5 秒，可能有最多 5 秒的误差。如需更灵敏可调小
   `StudyTimerApp` 中 `detectTimer` 的间隔（默认 5000 毫秒）。
